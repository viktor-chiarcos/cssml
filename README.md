# cssml

CSSML ist ein Modul, in dem HTML-Elemente aus CSS existieren

Katalog:
<details>

- u (Text Unterstreichen (unterstützt nur einmaliges Schreiben))

</details>

# cssml Verwenden

cssml kann eine Verbindung zu ihrem HTML-Dokument herstellen, wenn folgender Code ganz unten steht:

    <script src=https://raw.githubusercontent.com/viktor-chiarcos/cssml/refs/heads/main/cssml.js"></script>
